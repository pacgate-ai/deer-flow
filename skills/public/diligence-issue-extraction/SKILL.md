# 尽调问题抽取 Skill（百宸 A7→A3 衔接，diligence-issue-extraction）

**红线：** 按中国尽调 11 章体系抽取问题，三态标注，附页码引用，**不下定级**（定级归 A3 承办律师）。跨章线索只标"线索抄送 → <章>"，不越章下结论。任何需法律判断的字段标"待律师"。

## 一、与 tabular-review 的关系

`tabular-review` 产出**逐文件**审查表（文件名/类型/三态/关键条款/风险点/页码）。本 skill 读取审查表，按**中国尽调 11 章**体系**横向归集**问题——把分散在不同文件中的同一章问题汇总到一起，供 A3 各条线承办律师做实体分析。

```
数据室文档 → tabular-review（逐文件审查表）→ diligence-issue-extraction（11章问题清单）→ A3 条线 skill（实体分析+定级）
```

本 skill **不做** tabular-review 的逐文件审查，也**不做** A3 的实体分析/定级——只做中间的"按章归集"。

## 二、硬约束

1. **按 11 章归集**——每条问题归入对应章（见 §三 11 章体系）。归不进的标"待归类"，不强行归。
2. **三态标注**——每条问题：有问题/无问题/资料不足。"资料不足"不得推断补齐。
3. **页码引用**——每条问题附原文件页码/条款号。
4. **不下定级**——定级（P0–P3）归 A3 承办律师，本 skill 只标"有问题"供上游判断。
5. **跨章线索只抄送**——发现他章线索标"线索抄送 → <章>"，不越章下结论。
6. **反编造**——无来源留空不编。
7. **待律师**——需法律判断的字段标"待律师"。
8. **权限子集**——吞吐层权限子集，不调用法律检索、不下定级。

## 三、中国尽调 11 章体系（固定顺序）

1. 主体资格与历史沿革（设立、历次股权变更、出资瑕疵、增减资）
2. 公司治理（章程、三会决议、印章、对外担保程序）
3. 股权结构（代持、质押/冻结、对赌与回购、VIE/外资准入）
4. 主要资产（土地房产权属、知识产权、设备、特许资质）
5. 重大合同（控制权变更/转让限制条款、关联交易）
6. 债权债务与对外担保
7. 劳动人事与社保公积金（欠缴敞口、经济补偿、竞业）
8. 税务合规（股权转让税、土增/契税、特殊性重组、间接转让）
9. 环保与安全生产（排污许可、环评、土壤污染、安全生产）
10. 诉讼仲裁与行政处罚（含被执行/失信）
11. 业务资质与行政许可（可转让性、重新审批）

每条问题归入一章。跨章线索（如股权代持牵涉税务）标"线索抄送 → 第8章 税务"。

## 四、工作流

### Step 0 — 载入审查表 + 数据室索引　`tier: Low/本地 · data: 客户敏感`
读取 A7 `tabular-review` 产出的逐文件审查表 + 数据室索引。确认 11 章覆盖范围。

### Step 1 — 逐章问题归集　`tier: Low/本地 · data: 客户敏感`
对审查表中每条"有问题"或"资料不足"的项：
- 按 §三 11 章归入对应章
- 每条问题：章号 + 问题描述 + 三态 + 原文件页码引用 + 来源文件名
- 跨章线索标"线索抄送 → <章>"
- 归不进的标"待归类"

每章产出问题清单（表格：问题/三态/页码引用/来源文件/待律师/线索抄送）。

### Step 2 — 章级汇总　`tier: Low/本地 · data: 客户敏感`
每章汇总：
- 本章问题数（有问题/无问题/资料不足）
- 待律师项数
- 跨章线索抄送清单

### Step 3 — 入库（可选）　`tier: Low/本地 · data: 客户敏感`
问题清单存入 OpenViking `viking://resources/matters/<matter-id>/issues/`（受 OpenViking auth 配置约束，如 403 则仅写本地）。

### Step 4 — 输出
- **11 章问题清单**：每章一张表（问题/三态/页码引用/来源文件/待律师/线索抄送）
- **跨章线索抄送清单**：线索/源章/目标章/理由
- **章级汇总**：每章问题数/待律师/资料不足
- **待归类清单**（如适用）

## 五、本 skill 不做

- **不替 A3 做实体分析**——只归集问题，不分析法律效力。
- **不替 A3 下定级**——定级归承办律师。
- **不替 tabular-review 做逐文件审查**——只读取审查表横向归集。
- **不越章下结论**——跨章只抄送。
- **不编造**——无来源留空不编。
- **不直接进入交付件**——产出供 A3 承办律师逐项复核。
- 每条都是线索非结论，正式用前须律师核验。
