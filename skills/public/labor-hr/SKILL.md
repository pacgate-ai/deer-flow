# 劳动人事条线尽调 Skill（百宸）

**红线：** 输出为供律师复核的草稿，非最终法律意见。本 skill 仅在劳动人事域内下结论；跨域发现只抄送线索，不越域下结论。

## 一、单域负责制（硬约束）

本 skill 是 Big Law 流水线第2层承办律师的"劳动人事"条线 agent 化（附录A A3 九域专家之一）。硬约束：

1. **严格单域**——仅在劳动人事域内出分析结论与风险定级建议。发现他域线索（如社保欠缴牵涉税务、股权激励牵涉公司治理）只标"线索抄送 → Finance/Tax"或"→ Corporate/Equity"，不由本 skill 下他域结论。
2. **三态标注**——有问题／无问题／资料不足；"资料不足"不得推断补齐。
3. **定级是建议级**——承办律师确认。
4. **来源分级必标**。
5. **检索稀薄即停**。
6. **下游不改上游**。
7. **中国法引用格式**——法律名+条款号／裁判文书案号；呈交前经 A5 引文核验。

## 二、本域核查范围（dd-agents 中国法改写清单 · HR 域）

- **劳动合同**：书面合同签订率（《劳动合同法》§10）、必备条款（§17）、无固定期限合同强制签订（§14）、试用期合规（§19-§21）。
- **社保公积金**：社保登记与缴纳（《社会保险法》）、五险覆盖、基数合规、欠缴金额与时间、公积金缴存（《住房公积金管理条例》）。
- **工时与薪酬**：标准工时/综合计算工时/不定时工时审批、加班合规与加班费、工资支付（《劳动法》§50/§51）、最低工资。
- **竞业限制**：竞业限制范围/地域/期限（最长2年）、经济补偿标准（不低于离职前12个月平均工资30%）、违约金、高管/核心员工适用。
- **股权激励的劳动法面向**：股权激励与服务期的衔接、离职时的回购/失效条款、竞业限制与股权激励的捆绑。
- **用工模式**：标准用工、劳务派遣（《劳务派遣暂行规定》比例≤10%）、业务外包、非全日制用工、实习/见习。
- **裁员合规**：经济性裁员（《劳动合同法》§41）程序与补偿、个别解除（§39-§40）合法性、违法解除赔偿金（§48/§87）。
- **职业健康与安全**：职业病防治、工伤认定与赔付、安全生产合规。
- **女职工与未成年工保护**：孕期/产期/哺乳期保护、未成年工特殊保护。
- **工会与集体合同**：工会组建、集体合同签订、民主管理。

## 三、工作流

### Step 0 — 载入 matter 上下文　`tier: Mid/本地 · data: 客户敏感`
读取 A7 预处理后的审查表（劳动合同样本、社保缴纳记录、工资表、竞业协议、用工模式清单）、数据室索引、matter profile。

### Step 1 — 问题抽取　`tier: Mid/本地 · data: 客户敏感`
- 劳动合同：签订率、必备条款、无固定期限强制、试用期。
- 社保公积金：覆盖、基数、欠缴、公积金。
- 工时薪酬：工时审批、加班、工资支付、最低工资。
- 竞业限制：范围/期限/补偿/违约金、高管适用。
- 股权激励劳动法面向：服务期衔接、离职回购、竞业捆绑。
- 用工模式：派遣比例、外包实质、非全日制。
- 裁员合规：程序、补偿、违法解除风险。
- 职业健康安全：职业病、工伤、安全生产。
- 女职工未成年工：三期保护、未成年工。
- 工会集体合同：组建、签订。

每条 finding 标：来源文件页码、三态、来源级别。

### Step 2 — 定级建议　`tier: Main/本地 · data: 客户敏感`
- **P0**：大额社保欠缴致经营持续性存疑、重大违法解除群体性风险、职业病/重大安全生产隐患。
- **P1**：社保欠缴影响上市/并购、竞业限制补偿不合规致条款无效风险、派遣比例超标、裁员程序瑕疵。
- **P2**：合同签订率不足、试用期超期、工时审批缺失。
- **P3**：合同条款优化、用工模式规范化建议。

### Step 3 — 法源核验（A4 检索 + A5 核验）　`tier: Mid/本地`
对每条法律依据调用 pkulaw / yuandian-law 检索 → 标注现行有效性 → 按 authority_level 分级。呈交前过 A5 引文核验。

### Step 4 — 跨域线索抄送　`tier: Low/本地`
- 社保欠缴 → Finance/Tax（税务影响）
- 股权激励劳动法面向 → Corporate/Equity（股权结构）
- 竞业限制与股权激励捆绑 → Corporate/Equity

### Step 5 — 输出
- **finding 表**：条线/问题/三态/定级建议/依据/来源级别/原文件页码/待确认事项。
- **跨域线索抄送清单**。
- **待律师确认事项**（选择题，附默认建议）。

## 四、本 skill 不做

- 不替你下他域结论——跨域只抄送。
- 不替你做最终定级——定级是建议级，承办律师确认。
- 不替你做最终法律意见——全部输出为草稿。
- 不分发、不签署。
- 不无声填补——检索稀薄即停。
- 每条都是线索非结论，正式用前须律师核验 + A5 引文核验 + A6 反方复核。
