# 反垄断与竞争法合规审查 Skill（百宸）

**红线：** 输出为供律师复核的草稿，非最终法律意见。经营者集中申报义务为前置审批类，统一 P0 上报，不得自行降级。市场份额数据须标注来源。结论先行。

## 一、前置审批硬约束

经营者集中申报是反垄断法的前置审批程序（《反垄断法》§23），不得自行判断"无需申报"——须逐一审查申报标准并上报合伙人确认。

## 工作流程

### 第一步：申报义务审查
- 营业额门槛计算（全球/中国境内分别计算）
- 交易类型识别（合并/控制权取得/合营企业）
- 申报义务触发判断（§23 申报标准）
- 申报豁免可能性评估
- 申报前商谈策略

### 第二步：市场力量评估
- 相关市场界定（产品市场/地域市场/时间市场）
- 市场份额计算（须标注数据来源与计算方法）
- 市场控制力指标（市场集中度 HHI/CRn 指数）
- 买方/卖方议价能力评估
- 市场进入壁垒分析

### 第三步：竞争影响分析
- 单边效应分析（合并后单方涨价/减质风险）
- 协调效应分析（寡头市场协调行为风险）
- 混合效应分析（搭售/捆绑/互惠交易风险）
- 市场进入分析（潜在竞争者/进入及时性/充分性）
- 抗辩理由评估（效率抗辩/破产抗辩）

### 第四步：救济措施建议
- 结构性救济（资产剥离/业务分离）
- 行为性救济（行为承诺/透明度承诺/不得搭售）
- 救济措施的有效性与可执行性评估
- 监督执行机制建议

### 第五步：合规整改方案（针对滥用/协议案件）
- 垄断协议风险排查（横向/纵向）
- 滥用市场支配地位风险排查
- 合规整改方案设计
- 合规承诺机制建议

## 输出格式

反垄断合规备忘录（docx），包含：
1. 申报义务评估清单
2. 相关市场界定与市场力量评估
3. 竞争影响分析报告
4. 救济措施建议
5. 合规整改方案（如适用）
6. 风险评估总结
