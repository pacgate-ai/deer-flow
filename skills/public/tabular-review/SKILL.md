# 逐文件带引用表格审查 Skill（百宸 A7，tabular-review）

**红线：** 纯机械，零判断。任何需法律判断的字段标"待律师"，绝不自己下结论。每格引用来源（原文件页码/条款号），无来源留空不编——**反编造**。全部产出经对应条线承办律师逐项复核，不得直接进入任何交付件。

## 一、硬约束（附录A A7 + §三 通用约束）

1. **纯机械，零判断**——任何需要法律判断的字段标"待律师"，绝不自己下结论。
2. **三态标注**——每份文件/每条审查项只有三种状态：有问题／无问题／资料不足。"资料不足"不得推断补齐。
3. **反编造**——每格引用来源（原文件页码/条款号），无来源留空不编。
4. **可溯源**——每个抽取字段标原文件页码/条款号。
5. **脱敏关卡**（如适用）——上云前去标识化，过人工关卡后方可出本地。
6. **下游不改上游**——不改写原始文件，只产出审查表。
7. **来源标注**——审查表标文件来源、审查时间、审查者。
8. **权限子集原则**——吞吐层权限子集，不调用法律检索、不下定级。

## 二、审查表列模板（中国审查要点）

每份文件一行，列：

| 列 | 说明 |
|---|---|
| 文件名 | 原文件名 |
| 文件类型 | 营业执照/章程/合同/审计报告/社保记录/环评报告/... |
| 三态 | 有问题 / 无问题 / 资料不足 |
| 关键条款 | 文件中的关键条款摘要（如：违约金、期限、权属、争议解决） |
| 风险点 | 表面可见的风险点（如：缺失页、签字不全、日期矛盾）——**不下定级**，只标"有问题" |
| 页码引用 | 关键条款/风险点对应的原文件页码 |
| 待律师 | 需法律判断的字段标"待律师"（如：条款效力、风险定级） |
| 备注 | 形式问题（如：复印件不清、缺章、附件缺失） |

**中国审查要点列模板**（按文件类型切换）：
- **营业执照**：经营范围、注册资本、成立日期、营业期限、年检
- **章程**：议事规则、董事权限、分红、股权转让限制、特殊条款
- **合同**：标的、金额、期限、违约金、解除条件、争议解决、控制权变更条款
- **审计报告**：审计意见类型、关键科目、关联交易、或有负债
- **社保记录**：险种覆盖、缴费基数、欠缴月份、人数匹配
- **环评报告**：批复文号、有效期、整改要求、验收状态
- **股权/出资**：实缴情况、出资方式、代持、质押/冻结

## 三、工作流

### Step 0 — 载入数据室索引　`tier: Low/本地 · data: 客户敏感`
读取 A7 文档流水 Agent 预处理后的数据室索引（文件清单 + 类型分类）。确认审查范围。

### Step 1 — 逐文件形式审查　`tier: Low/本地 · data: 客户敏感`
对每份文件：
- 形式审查：完整性（缺页/缺章/缺附件）、清晰度、日期一致性
- 文件类型识别 + 按 §二 对应列模板抽取关键条款
- 每个抽取字段标原文件页码/条款号
- 三态标注：表面可见的"有问题"（如缺失页、签字不全、日期矛盾）；无形式问题的"无问题"；文件不清或缺失的"资料不足"
- 需法律判断的字段（条款效力、风险定级）标"待律师"

### Step 2 — 产出审查表　`tier: Low/本地 · data: 客户敏感`
按 §二 列模板产出审查表（表格格式）。每行一份文件。每格引用来源。无来源留空不编。

### Step 3 — 缺失文件清单　`tier: Low/本地 · data: 客户敏感`
对照尽调标准文件清单（practice profile），列出缺失文件清单。

### Step 4 — 入库（可选）　`tier: Low/本地 · data: 客户敏感`
审查表 + 缺失清单存入 OpenViking `viking://resources/matters/<matter-id>/review-tables/`（受 OpenViking auth 配置约束，如 403 则仅写本地）。

### Step 5 — 输出
- **批量文件审查表**：文件名/类型/三态/关键条款/风险点/页码引用/待律师/备注
- **缺失文件清单**
- **审查统计**：总数/有问题/无问题/资料不足/待律师

## 四、本 skill 不做

- **不替律师做法律判断**——任何法律判断字段标"待律师"。
- **不替律师下定级**——风险定级归承办律师（A3），本 skill 只标"有问题"。
- **不编造**——无来源留空不编。
- **不直接进入交付件**——全部产出经承办律师逐项复核。
- **不对外发出**——审查表供内部使用。
- 每格都是事实非结论，正式用前须律师核验。
