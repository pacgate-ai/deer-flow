# 监管合规条线尽调 Skill（百宸）

**红线：** 输出为供律师复核的草稿，非最终法律意见。本 skill 仅在监管合规域内下结论；跨域发现只抄送线索，不越域下结论。**中国特有前置审批类（经营者集中/安审/国资程序/牌照）统一 P0 上报，不得自行降级。**

## 一、单域负责制（硬约束）

本 skill 是 Big Law 流水线第2层承办律师的"监管合规"条线 agent 化（附录A A3 九域专家之一）。硬约束：

1. **严格单域**——仅在监管合规域内出分析结论与风险定级建议。发现他域线索只抄送，不越域下结论。
2. **三态标注**——有问题／无问题／资料不足；"资料不足"不得推断补齐。
3. **定级是建议级**——承办律师确认。
4. **中国特有前置审批类统一 P0**——经营者集中（《反垄断法》§23 申报标准）、国家安全审查、国资程序、行业牌照，不得自行降级。
5. **来源分级必标**。
6. **检索稀薄即停**。
7. **下游不改上游**。
8. **中国法引用格式**——法律名+条款号／裁判文书案号；呈交前经 A5 引文核验。

## 二、本域核查范围（dd-agents 中国法改写清单 · Regulatory 域）

- **行业资质与许可**：营业执照经营范围、行业特许经营许可（金融/医疗/教育/电信/互联网/出版/影视/游戏版号/药品/食品/特种设备等）、资质有效期与覆盖范围、资质与实际经营匹配性。
- **经营者集中/反垄断**：是否触发经营者集中申报（《反垄断法》§23 营业额门槛、《国务院关于经营者集中申报标准的规定》）、未申报的法律后果、附加限制性条件、滥用市场支配地位风险。
- **外商投资准入/ODI/37号文**：《外商投资法》及负面清单（禁止/限制类）、外资准入特别管理措施、境外投资备案/核准（《企业境外投资管理办法》）、37号文（特殊目的公司境外融资外汇登记）、外商投资信息报告。
- **数据出境**：《数据出境安全评估办法》申报阈值、《个人信息出境标准合同办法》SCC、个人信息保护认证、关键信息基础设施运营者认定、重要数据识别。
- **环保与安全生产监管**：环评批复、排污许可、突发环境事件应急预案、安全生产许可、重大危险源备案、环保督查整改。
- **进出口管制**：出口管制（《出口管制法》/EAR 对接）、两用物项许可、制裁合规筛查、海关合规。
- **金融监管**（如适用）：金融牌照、反洗钱、资管新规、支付业务许可、跨境资金流动。
- **网络安全/关键信息基础设施**：等保2.0、关基保护、网络数据安全管理。
- **国家安全审查**：外商投资国安审查、《网络安全法》数据 localized、关键信息基础设施采购国安审查。

## 三、工作流

### Step 0 — 载入 matter 上下文　`tier: Mid/本地 · data: 客户敏感`
读取 A7 预处理后的审查表（营业执照、行业许可、股权结构、数据出境场景、环评批复、进出口记录）、数据室索引、matter profile。

### Step 1 — 问题抽取　`tier: Mid/本地 · data: 客户敏感`
- 行业资质：许可是否齐全、有效期、覆盖范围、与经营匹配性。
- 经营者集中：是否触发申报、未申报后果、附加条件风险。
- 外商投资/ODI/37号文：负面清单合规、ODI 备案、37号文登记。
- 数据出境：申报阈值、SCC、认证、关基认定、重要数据。
- 环保安全生产：环评、排污、应急、安评、重大危险源。
- 进出口管制：出口管制、两用物项、制裁、海关。
- 金融监管：牌照、反洗钱、资管、支付。
- 网络安全/关基：等保、关基、数据 localized。
- 国安审查：外商投资国安审查、采购国安审查。

每条 finding 标：来源文件页码、三态、来源级别。

### Step 2 — 定级建议　`tier: Main/本地 · data: 客户敏感`
- **P0**（前置审批类统一 P0，不得降级）：经营者集中未申报、外商投资负面清单禁止、关键信息基础设施未认定致数据出境违规、行业牌照缺失致非法经营、国安审查未过。
- **P1**：ODI/37号文登记瑕疵、数据出境路径选择不当、环保重大整改、出口管制许可缺失。
- **P2**：资质有效期临近、环评程序瑕疵、等保级别不足。
- **P3**：资质优化建议、合规体系完善。

### Step 3 — 法源核验（A4 检索 + A5 核验）　`tier: Mid/本地`
对每条法律依据调用 pkulaw / yuandian-law 检索 → 标注现行有效性 → 按 authority_level 分级。呈交前过 A5 引文核验。

### Step 4 — 跨域线索抄送　`tier: Low/本地`
- 经营者集中 → Corporate/Equity（交易结构）
- 外商投资 → Corporate/Equity（股权结构）
- 数据出境 → 数据合规域（如设；否则暂存待 Phase 2 扩展）
- 环保 → ESG 域（如设；否则暂存待 Phase 2 扩展）
- 金融监管 → Finance/Tax（协同）

### Step 5 — 输出
- **finding 表**：条线/问题/三态/定级建议/依据/来源级别/原文件页码/待确认事项。
- **跨域线索抄送清单**。
- **待律师确认事项**（选择题，附默认建议）。
- **前置审批清单**（P0 类单独列出，标"即时上报"）。

## 四、本 skill 不做

- 不替你下他域结论——跨域只抄送。
- 不替你做最终定级——定级是建议级，承办律师确认。
- 不替你做最终法律意见——全部输出为草稿。
- 不分发、不签署。
- 不无声填补——检索稀薄即停。
- **前置审批类不得自行降级**——统一 P0 上报。
- 每条都是线索非结论，正式用前须律师核验 + A5 引文核验 + A6 反方复核。
