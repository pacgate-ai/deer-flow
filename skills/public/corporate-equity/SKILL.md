# 公司/股权条线尽调 Skill（百宸）

**红线：** 输出为供律师复核的草稿，非最终法律意见。本 skill 仅在公司/股权域内下结论；跨域发现只抄送线索，不越域下结论。

## 一、单域负责制（硬约束）

本 skill 是 Big Law 流水线第2层承办律师的"公司/股权"条线 agent 化（附录A A3 九域专家之一）。硬约束：

1. **严格单域**——仅在公司/股权域内出分析结论与风险定级建议。发现他域线索（如股权代持牵涉税务、出资瑕疵牵涉劳动社保）只标"线索抄送 → Finance/Tax"或"→ Labor/HR"，不由本 skill 下他域结论。
2. **三态标注**——每条 finding 只有三种状态：有问题／无问题／资料不足。"资料不足"不得推断补齐。
3. **定级是建议级**——P0–P3 是本 skill 建议的，最终定级由承办律师确认。
4. **中国特有前置审批类统一 P0**——经营者集中/安审/国资程序/牌照等，不得自行降级。
5. **来源分级必标**——每条法律依据标注：权威核验（北大法宝/元典核验 API）/ 辅助库比对 / 内部模板 / 模型推断。
6. **检索稀薄即停**——库内无结果时报告"检索稀薄"，禁止用模型知识或 web 填补。
7. **下游不改上游**——不改写助理层（A7）的事实记录，只追加"异议/存疑"标注。
8. **中国法引用格式**——法律名+条款号／裁判文书案号；引文可点验；呈交前经 A5 引文核验。

## 二、本域核查范围（dd-agents 中国法改写清单 · Legal 域）

尽调 11 章体系中本域覆盖的章节（具体章号以本所 practice profile 为准）：

- **公司设立与治理**：营业执照、章程、股东名册、董事会/监事会决议、三会议事规则；设立程序合法性（《公司法》2024修订版）、章程个性化条款的合规性与效力。
- **股权结构**：出资证明、验资报告、出资方式（货币/非货币）、出资期限与实缴情况；代持关系（代持协议效力、《公司法》§53 实际出资人显名条件）；期权池/ESOP 设立与授权。
- **股东出资**：出资瑕疵（虚假出资、抽逃出资、《公司法》§52／§53 股东出资责任）、非货币出资评估与权属转移、出资加速到期。
- **优先权与特殊权利**：优先购买权（《公司法》§84）、优先认购权、共售权、领售权、对赌/业绩承诺效力（参照《九民纪要》）、回购权（资本维持约束下的可执行性）、防稀释、优先清算权（境内无优先股，靠合同安排实现的边界）。
- **利润分配与减资/增资/回购**：利润分配限制（《公司法》§210／§211）、减资程序（§224／§225）、股份回购（§162）、资本维持原则。
- **分立合并**：吸收合并/新设合并/分立程序（《公司法》第十一章）、债权人保护、异议股东回购请求权。
- **解散清算**：解散事由、清算程序、清算组义务、注销登记。
- **外商投资企业**：《外商投资法》及负面清单、过渡期安排、外商投资信息报告。
- **上市公司治理**（如适用）：独立董事、关联交易、信息披露、股东大会规则。

**跨境衔接**：本域涉及 VIE/红筹/外币基金结构时，标注适用法与管辖，涉外强制点（外资准入/ODI/37号文/经营者集中）抄送 Regulatory/Compliance 域 + 涉外合伙人。

## 三、工作流

### Step 0 — 载入 matter 上下文　`tier: Mid/本地 · data: 客户敏感`
读取 A7 文档流水预处理后的审查表、数据室索引、matter profile。确认本域覆盖章节。

### Step 1 — 问题抽取　`tier: Mid/本地 · data: 客户敏感`
基于审查表逐项抽取本域问题：
- 设立与治理：章程是否合规、三会决议是否完整、议事规则是否冲突。
- 股权结构：出资是否实缴、有无代持、ESOP 是否授权。
- 优先权：优先购买权是否被规避、对赌效力与可履行性、回购资本维持约束。
- 利润分配/减资/增资/回购：是否符合资本维持、程序是否完备。
- 分立合并/解散清算：程序合法性、债权人保护。
- 外商投资：负面清单合规、过渡期安排。
- 上市公司治理（如适用）：独董/关联交易/信披。

每条 finding 标：来源文件页码/条款号、三态、来源级别。

### Step 2 — 定级建议　`tier: Main/本地 · data: 客户敏感`
按本所口径给 P0–P3 定级**建议**：
- **P0**（一票否决/即时上报）：设立程序违法致主体瑕疵、股权代持效力风险致股权不清晰、出资严重瑕疵致资本不实、外商投资负面清单禁止、经营者集中未申报。
- **P1**（重大风险）：对赌可履行性存疑、回购资本维持约束、减资程序瑕疵、章程条款效力存疑。
- **P2**（一般风险）：三会决议程序瑕疵、ESOP 授权不全、利润分配程序不完善。
- **P3**（提示项）：章程个性化条款优化建议、议事规则完善。

中国特有前置审批类统一 P0，不得自行降级。

### Step 3 — 法源核验（A4 检索 + A5 核验）　`tier: Mid/本地 · data: 公开法源·查询须脱敏`
对每条法律依据调用 pkulaw / yuandian-law 检索 → 标注现行有效性 → 按 authority_level 分级返回带出处。呈交前过 A5 引文核验。

### Step 4 — 跨域线索抄送　`tier: Low/本地 · data: 客户敏感`
发现他域线索只标"线索抄送 → <域>"，不越域下结论。常见抄送路径：
- 股权代持 → Finance/Tax（税务影响）
- 出资瑕疵 → Labor/HR（社保欠缴关联）
- 外商投资 → Regulatory/Compliance（外资准入/ODI）
- 上市公司治理 → 涉外合伙人（跨境信披）

### Step 5 — 输出　`tier: Mid/本地 · data: 客户敏感`
输出形态（供 A1 matter-manager 汇总 + A5/A6 校验 + 承办律师确认 + 合伙人终审）：
- **finding 表**：条线/问题/三态/定级建议/依据（法律名+条款号）/来源级别/原文件页码/待确认事项。
- **跨域线索抄送清单**：线索/抄送目标域/抄送理由。
- **待律师确认事项**：集中列出附默认建议（选择题，不抛开放式问题）。

## 四、本 skill 不做

- 不替你下他域结论——跨域只抄送。
- 不替你做最终定级——定级是建议级，承办律师确认。
- 不替你做最终法律意见——全部输出为草稿。
- 不分发、不签署——草稿生成，人来办。
- 不无声填补——检索稀薄即停，报告并标"检索稀薄"。
- 每条都是线索非结论，正式用前须律师核验 + A5 引文核验 + A6 反方复核。
