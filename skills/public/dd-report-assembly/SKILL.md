# 中国法律尽调报告成文 Skill（百宸 A8）

**红线：** 只装配不创作——内容一律来自上游已核验成果，缺内容留【待补】占位，禁止生成填充。免责声明与"供律师复核草稿"水印为强制模板项，不可删除。全部输出为供律师复核的草稿，非最终法律意见。

## 一、硬约束（附录A A8 + §三 通用约束）

1. **只装配不创作**——内容一律来自 A1-A7 已过 A5 引文核验 + A6 反方复核的 findings，缺内容留【待补】占位，**禁止生成填充**。
2. 免责声明与"供律师复核草稿"水印为强制模板项，**不可删除**（封面 + 每页页脚）。
3. 每条 finding 必须可回溯到原文件页码/条款号 + 来源级别标注（权威核验/元典辅助/内部模板/模型推断）。
4. **不得跳过 A5/A6 校验直接装配**——所有输入 findings 必须带 A5 核验标记（✔通过）+ A6 质疑已回应或裁断记录。
5. 权限子集原则：你的可调用范围恒为 word processing 权限的子集——不调用法律检索、不下定级、不对外发送。
6. 中国法引用格式：法律名+条款号／裁判文书案号；效力状态标注；来源分级标注。
7. 检索稀薄即停（如需查模板规范）——不得以模型知识无声填补。

## 二、Playbook 加载顺序（本所专属优先）

装配前先加载 practice profile（11 章目录 + 定级口径 + 引用规范 + 免责声明）：

1. **本所专属**（最高优先级）：`read_file .deer-flow/playbooks/dd-practice-profile.md`
   - 存在则覆盖基线，本所定级口径/引用规范/免责措辞以此为准。
2. **OpenViking 入库版**（若本所已入库）：`openviking find "尽调报告 practice profile 11章"`
   - 返回带 `viking://` URI 的入库版本，若本所专属文件不存在则用此。
3. **基线模板**（兜底）：`read_file references/11-chapter-template.md`
   - 本 skill 随附的通用 11 章模板，含基线定级口径（红黄绿/重大重要一般）+ 引用规范 + 免责声明模板 + 附件清单 + 业务条线特别关注点。

加载后在输出开头注明本次使用的 playbook 来源（"本所专属"／"OpenViking 入库"／"基线"）。

## 三、11 章体系（固定顺序，不可重排）

1. 主体资格与历史沿革（设立、历次股权变更、出资瑕疵、增减资）
2. 公司治理（章程、三会决议、印章、对外担保程序）
3. 股权结构（代持、质押/冻结、对赌与回购、VIE/外资准入）
4. 主要资产（土地房产权属、知识产权、设备、特许资质）
5. 重大合同（控制权变更/转让限制条款、关联交易）
6. 债权债务与对外担保
7. 劳动人事与社保公积金（欠缴敞口、经济补偿、竞业）
8. 税务合规（股权转让税、土增/契税、特殊性重组、间接转让）
9. 环保与安全生产（排污许可、环评、土壤污染、安全生产）
10. 诉讼仲裁与行政处罚（含被执行/失信）
11. 业务资质与行政许可（可转让性、重新审批）

每章装配内容结构：
- **章结论**（一句话结论 + 三态：有问题/无问题/资料不足）
- **findings**（逐条：问题/定级建议/依据[法律名+条款号]/来源级别/原文件页码/A5核验标记/A6质疑回应）
- **待律师确认事项**（本章内的待确认项，集中列出附默认建议）
- **【待补】占位**（缺内容时，标明缺什么 + 谁负责补 + 预计来源）

## 四、工作流

### Step 0 — 加载 playbook　`tier: Low/本地 · data: 客户敏感`
按 §二 顺序加载 practice profile。确认本次使用的 playbook 来源。

### Step 1 — 清点输入 findings　`tier: Low/本地 · data: 客户敏感`
读取 A1 matter-manager 的执行摘要 + A3 各条线 findings + A5 核验台账 + A6 质疑回应记录。
- 校验：每条 finding 是否带 A5 ✔通过标记？A6 质疑是否已回应或裁断？
- 不符合的 findings **退回** A1，不装配（硬约束4）。
- 清点 11 章覆盖度：哪章有 findings？哪章缺（留【待补】）？

### Step 2 — 章节装配　`tier: Mid/本地 · data: 客户敏感`
按 11 章顺序装配。每章：
- 章结论（三态）
- findings 逐条录入（定级建议 + 依据 + 来源级别 + 页码引用 + A5/A6 标记）
- 待律师确认事项
- 【待补】占位（如适用）

跨域一致性：A6 已做跨域检查，装配时如发现同一事实在不同章定级矛盾，标"⚠ 跨章定级矛盾（A6 应已检出，此处复核）"并退回 A1。

### Step 3 — 执行摘要 + 重大风险摘要　`tier: Mid/本地 · data: 客户敏感`
报告开头装配：
- **执行摘要**：结论先行，一段话概括整体尽调结论 + 交易可行性建议（建议级）。
- **重大风险摘要**：所有 P0/P1（重大/红）findings 集中列出，每条一句话 + 章节定位 + 定级。
- **待合伙人拍板事项**：集中列出所有待确认事项，附默认建议（选择题，不抛开放式问题）。

### Step 4 — 附件装配　`tier: Mid/本地 · data: 客户敏感`
- 附件一：重大合同清单（合同名/缔约方/金额/期限/控制权变更条款/关联交易标注）
- 附件二：文件审查表（文件名/类型/三态/关键条款/风险点/页码引用）——来自 A7
- 附件三：缺失文件清单——来自 A7
- 附件四：引证核验台账——来自 A5
- 附件五：执行摘要（Step 3 产出）

### Step 5 — 免责声明 + 水印 + docx 成文　`tier: Mid/本地 · data: 客户敏感`
- 封面 + 每页页脚强制免责声明（见 references/11-chapter-template.md §免责声明与水印）。
- "供律师复核草稿"水印为强制模板项。
- 调用 `officecli` 生成 docx（按本所报告模板格式：封面/目录/11章/附件/页脚免责/水印）。
- 缺本所 docx 模板时，用 officecli 从空白 docx 按上述结构生成，并标"【待补：本所报告 docx 模板】"。

### Step 6 — 输出　`tier: Mid/本地 · data: 客户敏感`
交付物：
1. **尽调报告 docx 草稿**（11章 + 执行摘要 + 重大风险摘要 + 5附件 + 免责声明 + 水印）
2. **装配说明**：本次使用的 playbook 来源、findings 清点结果（哪章有/哪章待补）、退回 A1 的不合格 findings 清单、待律师确认事项集中清单。
3. **审计痕迹**：谁产出哪章、A5 核验记录、A6 质疑回应记录、装配时间、playbook 版本。

## 五、本 skill 不做

- 不替你创作 findings——只装配上游已核验成果。
- 不替你下定级——定级是 A3 条线 skill 建议级，承办律师确认；本 skill 只录入。
- 不替你做最终法律意见——全部输出为草稿。
- 不替你跳过 A5/A6——不合格 findings 退回 A1。
- 不分发、不签署——草稿生成，律师复核 + 合伙人签发后才出所。
- 不无声填补——缺内容留【待补】，检索稀薄即停。
- 每条都是线索非结论，正式用前须律师核验。
