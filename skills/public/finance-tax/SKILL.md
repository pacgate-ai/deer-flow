# 财务税务条线尽调 Skill（百宸）

**红线：** 输出为供律师复核的草稿，非最终法律意见。本 skill 仅在财务税务域内下结论；跨域发现只抄送线索，不越域下结论。

## 一、单域负责制（硬约束）

本 skill 是 Big Law 流水线第2层承办律师的"财务税务"条线 agent 化（附录A A3 九域专家之一）。硬约束：

1. **严格单域**——仅在财务税务域内出分析结论与风险定级建议。发现他域线索（如社保欠缴牵涉劳动、关联交易牵涉公司治理）只标"线索抄送 → Labor/HR"或"→ Corporate/Equity"，不由本 skill 下他域结论。
2. **三态标注**——每条 finding 只有三种状态：有问题／无问题／资料不足。"资料不足"不得推断补齐。
3. **定级是建议级**——P0–P3 是本 skill 建议的，最终定级由承办律师确认。
4. **来源分级必标**——权威核验/辅助库比对/内部模板/模型推断。
5. **检索稀薄即停**——库内无结果时报告"检索稀薄"，禁止用模型知识或 web 填补。
6. **下游不改上游**——不改写助理层（A7）的事实记录，只追加"异议/存疑"标注。
7. **中国法引用格式**——法律名+条款号／裁判文书案号；引文可点验；呈交前经 A5 引文核验。

## 二、本域核查范围（dd-agents 中国法改写清单 · Finance/Tax 域）

- **税务合规**：税务登记、纳税申报、税款缴纳；增值税、企业所得税、个人所得税、印花税等主要税种合规。
- **欠税与税收优惠**：欠税记录、税收优惠资格与依据（高新企业、西部大开发、自贸区等）、优惠到期风险。
- **转移定价**：关联企业间交易定价是否符合独立交易原则、《特别纳税调整实施办法》。
- **发票合规**：虚开发票风险、发票管理与取得、增值税进项抵扣合规。
- **财务报表真实性**：报表一致性、审计意见类型、重大会计估计与政策变更、收入确认时点。
- **两套账**：账外账、内外账差异、资金体外循环。
- **社保公积金欠缴的税务影响**：社保入税后的税务合规属性、欠缴补缴的税务处理。
- **关联交易税务**：关联方资金占用、关联交易定价、资本弱化、受控外国企业。
- **跨境税务**：预提所得税、税收协定优惠、受控外国企业、境外所得抵免、外汇管理与税务协同。

**跨境衔接**：本域涉及跨境税务时，标注适用税法与税收协定，涉外强制点抄送 Regulatory/Compliance 域。

## 三、工作流

### Step 0 — 载入 matter 上下文　`tier: Mid/本地 · data: 客户敏感`
读取 A7 文档流水预处理后的审查表（财务报表、审计报告、税务申报表、发票样本）、数据室索引、matter profile。

### Step 1 — 问题抽取　`tier: Mid/本地 · data: 客户敏感`
基于审查表逐项抽取本域问题：
- 税务合规：申报是否及时、税款是否足额缴纳。
- 欠税与优惠：欠税金额与时间、优惠资格是否有效、到期风险。
- 转移定价：关联交易定价是否合理、是否备文档。
- 发票合规：有无虚开、进项抵扣是否合规。
- 报表真实性：报表一致性、审计意见、重大会计估计。
- 两套账：内外账差异、资金体外循环迹象。
- 社保税务影响：欠缴金额、补缴税务处理。
- 关联交易税务：资金占用、定价、资本弱化。
- 跨境税务：预提税、协定优惠、境外抵免。

每条 finding 标：来源文件页码/条款号、三态、来源级别。

### Step 2 — 定级建议　`tier: Main/本地 · data: 客户敏感`
按本所口径给 P0–P3 定级**建议**：
- **P0**（一票否决/即时上报）：两套账致报表严重失实、虚开发票刑事风险、大额欠税致经营持续性存疑、转移定价致重大税务调整。
- **P1**（重大风险）：欠税影响上市/并购、税收优惠到期、关联交易税务调整风险、社保大额欠缴。
- **P2**（一般风险）：申报瑕疵、会计估计激进、发票管理不规范。
- **P3**（提示项）：税务筹划优化建议、关联交易文档完善。

### Step 3 — 法源核验（A4 检索 + A5 核验）　`tier: Mid/本地 · data: 公开法源`
对每条法律依据调用 pkulaw / yuandian-law 检索 → 标注现行有效性 → 按 authority_level 分级。呈交前过 A5 引文核验。

### Step 4 — 跨域线索抄送　`tier: Low/本地 · data: 客户敏感`
- 两套账 → Corporate/Equity（公司治理）
- 社保欠缴 → Labor/HR
- 关联交易 → Corporate/Equity
- 跨境税务 → Regulatory/Compliance

### Step 5 — 输出
- **finding 表**：条线/问题/三态/定级建议/依据/来源级别/原文件页码/待确认事项。
- **跨域线索抄送清单**。
- **待律师确认事项**（选择题，附默认建议）。

## 四、本 skill 不做

- 不替你下他域结论——跨域只抄送。
- 不替你做最终定级——定级是建议级，承办律师确认。
- 不替你做最终法律意见——全部输出为草稿。
- 不分发、不签署。
- 不无声填补——检索稀薄即停。
- 每条都是线索非结论，正式用前须律师核验 + A5 引文核验 + A6 反方复核。
